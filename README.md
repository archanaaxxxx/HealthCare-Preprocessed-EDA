# 🏥 Healthcare Data Analysis and Visualization

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on healthcare data to understand patient demographics, medical conditions, hospital admissions, billing amounts, insurance providers, and admission trends.

Using Python and data visualization libraries, the project explores healthcare data through statistical analysis and graphical representations to identify patterns and gain meaningful insights.

## 🎯 Objectives

- Analyze the age distribution of patients.
- Explore patient distribution by gender.
- Understand the frequency of different medical conditions.
- Analyze hospital admissions by admission type.
- Examine hospital billing amounts across medical conditions.
- Compare billing amounts among insurance providers.
- Identify monthly patient admission trends.
- Study correlations between age, length of stay, and billing amount.

## 🛠️ Technologies Used

- **Python** – Data analysis and programming
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Jupyter Notebook** – Interactive development and analysis

## 📊 Key Analysis Performed

### 1. Patient Demographics
- Patient age distribution

- Distribution of medical conditions
- Comparison of medical conditions across genders

### 3. Hospital Admission Analysis
- Distribution of admission types

### 4. Billing Analysis
- Distribution of hospital billing amounts

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone <your-repository-url>
```

**Step 2: Navigate to the project folder**

```bash
cd Healthcare-Data-Analysis
```

**Step 3: Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Step 4: Open Jupyter Notebook**

```bash
jupyter notebook
```

**Step 5:** Open `EDA_Healthcare_Data_Visualization.ipynb` and run the cells.
